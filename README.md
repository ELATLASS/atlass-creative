## Structure
- `photography/` — Canon R8 photos, 500px gallery
- `music/` — AI-generated fusion tracks (Gnaoua x Electro House)
- `drone/` — Drone footage and inspection projects
- `design/` — Graphic design assets (stickers, t-shirts for Maroc of Design)
- `assets/` — Raw assets and metadata
